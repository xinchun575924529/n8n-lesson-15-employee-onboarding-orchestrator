员工入职编排引擎

一条 Webhook 打通 HR / IAM / IT / SaaS 四个系统：自动建档、开号、派单、开应用，三态报告动态回 201 / 207 / 502。零凭证、零费用、开箱即跑。

🔧 它做什么

POST 新员工资料→字段校验→HR 建档→IAM 开号→IT 派单→SaaS 开应用→三态报告

单个系统挂了不炸全链：其余照常执行，最后如实回 207 partial。调用方传 simulateStatus: 500 即可演练故障场景。

⚠️ 独家发现：原版模板有个缺陷

字段校验失败（缺姓名/邮箱非法）时流程不会停下，照样调完四个系统再回 201。课程里带你用三处改动修复（加 If 短路回 422），这正是企业级编排和玩具流水线的分水岭。
