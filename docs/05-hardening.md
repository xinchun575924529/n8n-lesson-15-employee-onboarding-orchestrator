# 05 · 生产化加固清单

## 已在 workflow-custom.json 实现

1. **校验短路**：「收集校验结果」后插 If 节点，`valid=false` → 直接回 **422** + issues 明细 + requestId，不再触达下游四系统

## 建议继续加（练习素材）

2. **幂等键**：以 requestId 做幂等，重复请求直接回首次结果（防 OA 重试造成重复建档）
3. **补偿/回滚（Saga）**：任一环节失败时，逆向调用已成功系统的「撤销」接口（如 IAM 销号）
4. **并行化**：HR 成功后 IAM/IT/SaaS 三者其实可并行（n8n 分支 + Merge），全链时长可砍半
5. **超时与重试**：HTTP 节点加 timeout + 指数退避重试（n8n 节点自带 retryOnFail）
6. **审计落库**：每段记账块写一份到数据库/表格，供合规审计
7. **鉴权**：webhook 加 Header Auth 或 HMAC 签名校验，防任意人触发入职
8. **敏感字段脱敏**：日志/错误响应里的邮箱、姓名做掩码

## 运维侧

- 工作流级 Error Workflow 接管异常，飞书/邮件告警
- 激活 + 重启后做冒烟（本课 C 关三发即最小冒烟集）
