# 获客短视频脚本（60s 横屏）

## 暗号：【入职】

## 口播稿（每段 ≤30 字）

**[钩子 0-5s]**
新员工入职要在 4 个系统开账号，你还在一个个手动点？

**[痛点 5-15s]**
HR 建档、IAM 开号、IT 派单、SaaS 开应用——漏一个，新人第一天就干瞪眼。

**[演示 15-40s]**
看这条 n8n 流水线：一条 POST 请求发过去，
四个系统自动依次开通，
哪个成功哪个失败，一份报告清清楚楚，
成功回 201，部分失败回 207，全灭回 502。
最骚的是——不用花一分钱，连 API key 都不需要。

**[价值 40-50s]**
这套「跨系统编排」思路，入职、离职、开通权限全都用得上。

**[CTA 50-60s]**
评论区扣【入职】，完整教程和工作流 JSON 直接发你。

## 画面建议

- 0-5s：HR 手忙脚乱切 N 个后台的素材/表情包
- 15-40s：n8n 画布录屏（整条链高亮流动）+ curl 发送 + 返回 JSON 特写
- 40-50s：三个变体场景字卡（入职/离职/权限开通）
- 50-60s：课程站二维码 + 暗号
